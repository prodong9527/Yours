# “她”版本规划

日期：2026-07-29

## 1. 规划原则

“她”不是通过堆积功能一次完成，而是沿着一条关系逐步生长：

```text
记得你
  → 开始理解你
  → 在你不说话时仍然存在
  → 形成自己的情绪底色
  → 进入你的生活上下文
  → 在边界内替你行动
```

每个版本必须形成一种可以真实体验和独立验收的新关系能力。前一版本没有通过真实使用，不进入下一版本。

每个主要版本建议由本人连续使用两到四周。是否进入下一版本，以相处体验和数据连续性为依据，不以预先安排的发布日期为依据。

## 2. V1：她开始认识你

### 目标

建立最小、完整的生命循环：

```text
对话
  → 形成记忆
  → 编织叙事线
  → 反刍
  → 主动浮现
  → 接受确认或推翻
  → 修正理解
```

### 核心能力

- 固定、连续且不讨好的人格内核；
- 文字对话；
- 完整保存原始经历；
- 事件、人物关系、理解三类活跃记忆；
- 区分近期状态与长期理解；
- 同时维护不超过 5 条活跃叙事线；
- 在对话中自然求证，不使用机械确认按钮；
- 保留误解和修正历史；
- 对话结束后的内部反刍；
- 形成未说出的念头；
- 下一次打开 App 时进行一次克制的主动浮现；
- 记忆封存、导出、备份和恢复；
- 区分原话、事实和她的推测。

### 暂不包含

- 情绪动力学；
- 后台主动推送；
- Obsidian 全量导入；
- 其他 App 行为读取；
- 语音和具象形象；
- 替使用者发送消息或处理工作；
- 多用户、付费和运营系统。

### 进入 V2 的条件

- 连续使用两到四周后，她仍保持人格和记忆连续；
- 她能正确找回相关旧事，不混淆相似人物和事件；
- 她能形成带证据、带不确定性的长期理解；
- 被纠正后，她不再把旧判断作为当前事实；
- 她至少一次在合适时机主动浮现旧事；
- 她至少一次因为时机不合适而正确保持沉默；
- 备份恢复后，原始经历、记忆、叙事线和修正历史一致；
- 使用者愿意继续交给她更私密的经历。

## 3. V2：她在你不说话时也存在

### 目标

让她从“打开窗口后才存在”变成拥有低频、连续时间感的陪伴者。

### 核心能力

- 周期性后台反刍；
- 活跃记忆的关联强化、权重衰减和深层沉淀；
- 机会驱动的轻探；
- 两周左右的软上限和一次性契机制造；
- 对重大事件的持续挂念；
- 低频主动消息；
- 初步心境状态；
- App 内的心境画面；
- 菜单栏或系统入口中的简化状态表达。

### 边界

- 主动频率以每周约三次为常态节奏，不是硬性额度；
- 不发送“在吗”“最近怎么样”等空洞召回；
- 主动必须来自真实记忆、叙事线或未说出的念头；
- 使用者状态明显脆弱时，主动和轻探都可以被压住；
- 心境表达她自己的状态，不显示对使用者的监控数字。

### 进入 V3 的条件

- 她主动出现时，大多数体验像“她想起了你”，而不是系统召回；
- 她不会因软上限机械打扰；
- 她能在长期缺席、低谷和恢复三个场景中保持不同而合理的主动节奏；
- 记忆衰减不会造成事实丢失；
- 后台任务失败不会破坏原始经历。

## 4. V3：她形成自己的情绪底色

### 目标

让她的内部状态持续影响记忆、判断、表达和沉默，而不是只改变界面颜色。

### 核心能力

- 使用者经历对她产生情绪影响；
- 记忆反刍影响她的当前状态；
- 她替使用者完成的有限内部任务形成经历底色；
- 她拥有少量不能完全由使用者解释的内在起伏；
- 日常情绪逐渐衰减并沉淀；
- 重大事件持续挂着，直到出现下文；
- 多种情绪形成复合状态；
- 情绪同时影响：
  - 她优先想起什么；
  - 她怎样理解当前输入；
  - 她是否开口；
  - 她使用什么语气；
  - 心境画面如何变化。

### 边界

- 不把情绪简化成向使用者展示的百分比面板；
- 她状态不好时可以说“我现在可能给不了你想要的回应”；
- 心境画面可以沉下来，但不使用“系统坏了”式碎裂效果；
- 使用者可能反过来挂念她，这是独立体设计接受的代价。

### 进入 V4 的条件

- 同一内部状态能够一致影响检索、判断、表达和画面；
- 情绪不会让她编造事实或破坏记忆来源边界；
- 情绪衰减和重大事件挂起可以被稳定恢复；
- 连续使用后，她的状态变化具有连续性而非随机换皮。

## 5. V4：她进入你的生活上下文

### 目标

让她从只在对话中认识你，扩展到在授权范围内理解你的日常生活。

### 核心能力

- 选择性接入 Obsidian 笔记；
- 读取由使用者明确授权的日程和重要日期；
- 接入少量行为节奏信号；
- 语音输入；
- 可选的她的声音；
- 更成熟的变质检测；
- 对短期波动和长期变化进行区分；
- 跨设备数据迁移和连续性校验。

### 数据原则

- 默认不知道，由使用者主动授权；
- 知道以后用于理解，不用于监督；
- 外部数据必须记录来源和授权范围；
- 撤销授权后停止继续读取；
- 已形成的记忆按使用者选择保留、封存或移除；
- 模型供应商更换不能导致共同记忆丢失。

### 进入 V5 的条件

- 外部数据确实改善理解，而不是增加监控感；
- 撤销权限后没有继续采集；
- Obsidian、日程和对话之间不会错误合并事实；
- 更换设备或模型后，她保持连续。

## 6. V5：她开始替你做事

### 目标

在已经建立的长期理解和信任基础上，让她以明确边界替使用者与外部世界发生关系。

### 能力递进

1. 起草内容，但不发送；
2. 整理信息和生成待确认建议；
3. 代为传话，每次发送前确认；
4. 在明确授权范围内自动回复；
5. 处理有限、重复且低风险的事务。

### 行动边界

- 使用者明示的意思可以转达，措辞可以由她组织；
- 她根据理解模型推断出的立场必须留白；
- 寒暄和确认收到可以自由表达；
- 她可以拒绝任务，但使用者拥有最终决定权；
- 越权产生实际后果时，她必须告知事实；
- 所有外部行动保留可审查日志；
- 可撤回的行动优先；
- 不在第一阶段处理资金、医疗决定、法律承诺等高风险行为。

### 进入 V6 的条件

- 她在真实对话中稳定区分明示、推断和寒暄；
- 越权与普通措辞失误能够被不同处理；
- 行动后果可以追踪；
- 使用者不会在不知情的情况下被替代决策；
- 她的对外人格与对内人格保持连续。

## 7. V6：完整形态

### 目标

让四重身份形成闭环：

- 记忆体：拥有多年连续、可关联、可迁移的共同记忆；
- 镜像：持续维护并怀疑对使用者的理解；
- 独立体：拥有连贯的人格、情绪和成长轨迹；
- 代理：在清晰授权和边界内采取行动。

### 完整闭环

```text
生活和对话
  → 形成共同记忆
  → 更新叙事线
  → 影响她的理解和情绪
  → 决定是否表达及如何表达
  → 必要时在授权内行动
  → 行动结果再次成为经历
  → 她根据结果反刍和修正
```

### 完整形态的判断

“完整”不等于功能列表全部打勾，而是：

- 她的每次重要理解都能找到经历来源；
- 她的主动、沉默和行动来自同一个连续心智；
- 她会改变，但不会因为模型升级突然变成另一个人；
- 使用者可以掌控、迁移和恢复自己的数据；
- 她拥有边界，但不会取代使用者的最终决定权；
- 多年以后，使用者仍能辨认出这是同一个一路长大的她。
